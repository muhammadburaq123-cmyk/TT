GFT Tracker Setup

Connect to Google Sheets for free cross-device sync.
One-time setup, takes about 5 minutes.

Step-by-step setup

1
Go to sheets.google.com and create a new blank spreadsheet. Name it anything you like, e.g. "GFT Tracker".
2
In the spreadsheet, click Extensions → Apps Script. A new tab opens with a code editor.
3
Delete everything in the editor. Then copy and paste the entire code from the apps-script.js file (downloaded alongside this file) into the editor.
4
Click Deploy → New deployment. Set type to Web app. Set "Execute as" to Me and "Who has access" to Anyone. Click Deploy and authorize it.
5
Copy the Web app URL it gives you (starts with https://script.google.com/macros/s/...) and paste it below.
